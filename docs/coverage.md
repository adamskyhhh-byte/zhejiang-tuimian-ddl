## 盘点方法与状态

- 逐校关联官方名单 DOC/XLSX；选调名单归属、职位专业限制与计算学科相关性分别记录。
- 从官网院系/机构目录、硕士招生目录、学校研招入口和学院栏目发现培养单位；参考站只提供公开 URL 线索，时间以官方正文、附件或 API 为依据。
- 学校级通知只在证据明确对应学院、项目和硕士范围时适用；学院专属时间优先核对，不将总系统截止自动套用到学院。
- 原网址更新、延期、多批次、硕博不同截止及日期精度分别记录；名称别名通过官方证据合并，映射与原因见 `data/unit-aliases.json`。
- “已发现公告”表示存在项目记录，不等于所有报名时间均已核验；“盘点待完成”表示相关单位或专业全集尚待补充，可以与已发现公告同时存在。
- “暂未检索到当年公告”仅表示已配置范围内的检查结果；深层栏目、新设学院、动态验证页面和扫描附件仍可能需要人工补充。来源访问异常和超过 36 小时未成功检查分别显示。
