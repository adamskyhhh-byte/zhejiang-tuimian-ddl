# 筛选类别口径

院校类别是便于检索的标签，不是浙江选调资格认定，也不表示学校或专业的统一排名。数字为当前招生季的报名项目数，不是学校数。同组多选取并集，不同组与学校、地区、学科等条件取交集；类别可重叠，因此各类别数量不能相加当作项目总数。

| 标签 | 本站含义 |
| --- | --- |
| TOP2 | 北京大学、清华大学的常用检索简称 |
| 港三 | 香港大学、香港中文大学、香港科技大学；本次 68 所范围无对应学校，显示 0 |
| 华五 | 复旦大学、上海交通大学、南京大学、浙江大学、中国科学技术大学 |
| C9 | TOP2、华五，加哈尔滨工业大学、西安交通大学 |
| 985 | 教育部原“985工程”名单，包含 TOP2、华五和 C9 |
| 211 | 教育部原“211工程”名单，包含其中的 985 高校 |
| 双非 | 本站采用“非985、非211”口径；其中可以有双一流高校 |
| 四非 | 在双非基础上，排除2022年第二轮“双一流”建设名单高校，作为检索简称 |
| 研究院 | 本条培养单位名称为研究院或研究所，包括大学所属单位；不把普通学院都视作研究院 |
| 联培 | 官方证据明确本条硕士项目为联合培养，并人工登记 `programTags: ["joint"]`；公告提及直博联培不自动给硕士加此标签 |

学校标签映射位于 `src/lib/school-tags.json`，68 个机构各有一项；中央党校不强行套用普通高校工程类别。985、211 使用历史名单，中国科学院大学等非211高校的研究实力不由这些标签判断。

## 报名状态和考核形式

- “开放”对应已核验且正在接受报名的项目；“已结束”对应报名截止已到的项目。完整状态筛选保留待核验、开放时间未知、即将开放和已取消。
- “线上／线下／混合”指考核、面试或复试形式，依据当季官方方案；线上填表或提交 PDF 不代表线上考核。
- “未核验”表示考核形式尚未得到明确证据确认，与报名时间的核验状态分别记录。
- 时间未知、未抓取或抓取失败的项目不会被归为“未开始”。

## 官方名单依据

- [教育部“985工程”学校名单](https://www.moe.gov.cn/srcsite/A22/s7065/200612/t20061206_128833.html)
- [教育部“211工程”学校名单](https://www.moe.gov.cn/srcsite/A22/s7065/200512/t20051223_82762.html)
- [教育部等三部门第二轮“双一流”建设名单](https://www.moe.gov.cn/srcsite/A22/s7065/202202/t20220211_598710.html)

这些名单用于本页标签口径；学校收录范围仍以浙江2026选调公告附件为准，不随筛选标签扩大。
