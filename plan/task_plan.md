# 浙江选调院校硕士预推免 DDL 信息网实施计划

## 目标与已确认边界
公开 GitHub 仓库与 Pages 网页；2026 年秋报名、2027 级硕士预推免（学硕、专硕）；不收夏令营、正式推免、仅直博。浙江 2026 常规与紧缺名单并集 68 个机构；国科大含相关研究所；广泛计算交叉方向。官方证据明确项自动发布，疑难待核验，无付费 AI 依赖。

## 验收约束
日期与时刻精度分离，固定北京时间；报名/材料/考核时间分离；不同批次独立，延期不改 ID；源失败不删除旧数据；每个来源 36 小时新鲜度独立计算；覆盖状态如实标记，不能将待核验说成全量核实。
